# Cyber Skill Hub – Personal Portfolio
🔗 [Live Portfolio](https://hariomsingh045.github.io/Portfolio/)

This is my personal portfolio website built to showcase my skills, projects, and learning journey in **Cybersecurity and Web Development**.

Unlike template-based portfolios, this project is structured, customized, and refined manually to ensure clarity, readability, and professional standards expected in real-world development.

## ✨ Features
- Clean and minimal UI
- Responsive design
- Structured components
- Easy-to-read Tailwind styling
- Recruiter-friendly project layout

## 🛠 Tech Stack
- Vite
- TypeScript
- Tailwind CSS
- Modern ES6+ JavaScript

## 📌 Purpose
This portfolio is designed for:
- Resume & placement reviews
- Internship applications
- Personal branding
- Skill demonstration

## 🚀 Running Locally
```bash
npm install
npm run dev
```
